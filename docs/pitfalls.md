## 三、金标惯例(实证有效的修法)

- 金标实验: go test 前后生产 data/ md5 快照 diff = 隔离的最硬证明。
- serve↔磁盘 md5 全等 = 纯前端批零重启的生效自证。
- 集合守卫: staged 文件集合精确计数(如 N=3+H), 集合外即拦截不落袋。
- 锚点 assert+括号 delta 前置: 结构断言在写盘前跑; 解析期自爆优于运行期写盘失败(引号笔误零损耗实证)。
- env 复刻重启: /proc/PID/exe + /proc/PID/environ = 零代码变更换启生产进程。
- t.Parallel 守卫: chdir 类批前置查根包并行测试。
- retry 只改守卫不改手术: 连闯三雷全绿 = 手术干净、雷在守卫层(口径修正吸收)。
