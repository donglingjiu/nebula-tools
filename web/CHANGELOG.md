# Nova Tools — 版本变更记录

## Brand refresh / 2026-10-16

- 将用户可见品牌从 `Nebula Tools` 统一改为 `Nova Tools`，管理端标识统一为 `Nova Admin`。
- 更新 HTML 页面标题、页面描述、加载提示、页面文案、AI 模型演示名称、系统通知与管理后台文案。
- 将演示账户邮箱域名、会话存储键和 CSV 导出文件名同步迁移为 Nova 命名。
- 将项目目录名统一为 `nova-ai-preview`，避免交付目录继续使用旧品牌名称。
- 保留原有 11 个用户端页面、10 个管理端页面以及本地静态交互结构。
- 未引入新的第三方运行时依赖。

## 版本边界

本项目仍是前端静态交互原型；品牌替换和交付梳理不代表真实服务端、AI API、身份认证或数据库已经接入。
