# Nova Tools — AI Productivity UI Prototype · Brand Refresh

一套无运行时框架依赖的多页面静态前端原型，采用“深空科技主视觉 + 清爽浅色工作区 + 雾紫/暖色点缀”的视觉语言。不同任务页面采用有区分的视觉节奏：AI 对话使用沉浸式深色工作台，文件处理偏暖白操作台，数据洞察强调图表可读性，工作流突出节点关系，管理后台强调密度与秩序；品牌、键盘操作、弹窗与反馈行为保持一致。

## 本地预览

推荐通过本地 HTTP 服务打开，避免浏览器对本地文件某些能力的限制：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 用户前台页面

- `index.html` 首页与常用工具
- `tools.html` 工具大全、搜索与分类筛选
- `ai.html` AI 对话工作台、快捷提示词、模型设置弹窗
- `workspace.html` 文件处理工作台、本地文件选择/拖拽、处理队列演示
- `tool-detail.html` PDF 转换工具详情
- `analytics.html` 数据洞察、SVG 趋势图与 CSV 导出
- `workflows.html` 智能工作流、节点预览与创建弹窗
- `profile.html` 个人中心、偏好与连接服务
- `mobile.html` 移动端响应式预览
- `login.html` 登录流程演示
- `help.html` 帮助中心与 FAQ 搜索

## 管理后台页面

- `admin/index.html` 管理总览
- `admin/users.html` 用户管理、搜索、筛选、添加用户
- `admin/tools.html` 工具目录、启停开关与新增工具
- `admin/analytics.html` 运营分析与可视化
- `admin/content.html` 内容与公告管理
- `admin/roles.html` 角色权限矩阵
- `admin/logs.html` 系统日志检索
- `admin/exports.html` 数据导出与 CSV 文件生成
- `admin/notifications.html` 通知配置
- `admin/settings.html` 系统、AI 服务和安全设置

## 交互包含

- 真实页面链接与活动导航状态
- `Ctrl/⌘ + K` 打开快速命令面板，搜索并跳转页面
- 搜索过滤、分类筛选、标签页、可切换开关、用户菜单
- 带模糊遮罩、焦点定位、Esc 关闭与点击遮罩关闭的高级弹窗
- Toast 反馈、AI 对话模拟、提示词快捷填充
- 本地文件选择/拖拽并列出队列（不会上传文件）
- 本地演示 CSV 导出
- 桌面和移动端响应式布局、`prefers-reduced-motion` 支持

## 重要边界

这是一套静态前端演示，不包含真实数据库、登录认证、文件转换服务器或大模型 API。AI 回复、运营数据及管理操作都是演示状态；不要在真实生产环境中使用静态前端保存密钥、授予权限或处理敏感文件。

“千万级并发”不能由静态页面本身保证。若面向大规模访问，需要单独规划 CDN/边缘缓存、静态资源指纹与缓存策略、身份认证、API 网关、限流、异步任务队列、数据库读写扩展、对象存储和监控压测。当前原型尽量保持无第三方运行时依赖，静态资源较少，便于后续采用 CDN 部署。


## 视觉与交互原则

- 不强求每个界面长得一样：使用共享设计语言，但按页面任务选择不同的表面、强调色与信息密度。
- 首页用深空主视觉建立科技识别；AI 工作台用沉浸式深色对话区；文件处理使用更明亮、暖色的操作区域；分析页优先保证图表层级；管理端用稳定的深色侧栏与浅色内容区。
- 微交互包括按钮高光、卡片光照跟随、悬浮微位移、页面进入过渡、不同类型的上下文弹窗，以及键盘命令面板。
- 仅使用本地 HTML/CSS/JavaScript 与内嵌 SVG 图标，无外部运行时框架依赖。
