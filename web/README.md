# Nova AI — 静态前后台原型 V6

这是以 **Nova** 为统一品牌的纯静态网站原型，采用原生 HTML、CSS、JavaScript 和 SVG 图标，不需要构建步骤或前端框架运行时。

## 快速预览

在本目录打开终端运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。建议通过本地 HTTP 服务运行，不要直接双击 HTML 文件，以确保相对路径、下载和浏览器 API 行为一致。

## 主要入口

- `index.html`：Nova 首页，水晶星环主视觉与快捷工作入口。
- `tools.html`：工具大全，支持搜索、分类筛选和工具详情跳转。
- `ai.html`：AI 对话工作台，包含消息流、快捷提示词、模拟思考状态和摘要操作。
- `workspace.html`：文件处理工作区，支持本地文件选择/拖放、队列展示和演示处理状态。
- `analytics.html`：数据洞察中心，包含指标、趋势图、分类图和 CSV 示例导出。
- `requirements.html`：需求分析工作台，包含需求输入、分析模式、结构化结果标签、文件选择和演示分析。
- `developer.html`：开发工具实验室，包含 JSON 编辑、格式化、校验、复制与结构预览。
- `workflows.html`：流程编排与运行记录演示。
- `profile.html`、`mobile.html`、`login.html`、`tool-detail.html`、`help.html`：账户、移动端展示、登录、工具详情和帮助页面。
- `admin/index.html`：管理后台首页。其余后台页包括用户、工具、运营分析、内容、权限、日志、导出、通知和设置。
- `design-gallery.html`：13 张已生成独立页面设计参考图与实际 HTML 页面映射，可点击打开真实交互页面。

## 当前设计参考映射

`design-reference/approved-single-page/` 包含本轮采用的 13 张独立参考图：前台 10 张、后台 3 张。缺少独立设计图的 7 个后台页面使用同套后台信息架构和默认专业工作台布局。参考图用于指导设计，不是直接作为页面背景；按钮、表格、输入框、弹窗和导航由 HTML/CSS/JS 构建。

视觉策略不是所有页面强制统一：主页突出水晶核心和星环；用户工作区采用清爽海天蓝白、柔和紫色点缀和高可读性；AI 对话更沉浸；文件工作台更偏任务效率；开发工具突出编辑器；后台使用专业深蓝侧栏和浅色数据区域。

## 可交互内容

- 顶部导航和管理侧栏页面跳转；
- `Ctrl + K`（macOS 可用 `⌘ + K`）打开快捷命令面板；
- 按钮悬浮/按下动效、卡片微位移、输入焦点环、下拉菜单、Toast 提示；
- 弹窗淡入缩放、背景模糊，支持点击遮罩或按 `Esc` 关闭；
- 工具搜索与分类筛选、AI 对话演示、需求分析演示、JSON 格式化/校验、本地文件列表与处理队列、CSV 示例导出；
- 响应式布局和 `prefers-reduced-motion` 减少动效支持。

## 真实服务边界

当前为静态前端原型。AI 回复、运营指标与后台部分操作是演示数据；本地文件交互不会自动上传到服务器，也没有真实用户认证、数据库、文件转换 API 或模型 API。生产版应将模型密钥保存在服务端，并接入认证/授权、任务队列、文件安全扫描、日志、CDN、缓存和速率限制。静态页面本身无法保证千万级并发，需要实际服务架构与压测验证。
