# Nova V6 设计说明

- **首页：** 采用水晶核心、星环轨道与柔和的海天背景作为主视觉。核心水晶使用从已确认首页参考图提取的独立艺术裁切，标题、搜索框、工具卡、快捷入口和手机预览仍由可交互 HTML 构成。
- **用户工作区：** 以海天蓝白、珍珠白和淡紫为基础，提供清楚的任务分区与柔和玻璃卡片，降低长时间使用的视觉负担。
- **AI 对话：** 对话流与 AI 结果区域分层呈现，输入框聚焦反馈、快捷提示词、思考状态和复制/转工作流操作各自有独立层级。
- **文件处理：** 拖放上传、格式选择、队列状态和文件预览作为主线，颜色主要用于文件类型与状态反馈。
- **需求分析：** 分步流程、需求描述、分析模式、补充文件和结构化结果分区，方便从想法到产品方案。
- **开发工具：** 深色代码编辑器作为视觉焦点，外层仍采用明亮工作台；提供 JSON 格式化、校验、复制与结构预览。
- **数据洞察：** 指标、趋势图、分类比例与 AI 建议分区，图表以轻量 SVG 实现，强调可读性。
- **管理后台：** 深蓝侧栏与浅色数据区域搭配，表格密度更高，适用于用户、工具、权限、日志、内容和配置等管理任务。
- **微交互：** 页面入场、按钮高光、轻微位移、下拉菜单、弹窗淡入缩放、模糊遮罩与 Toast 反馈；支持 Esc 关闭、键盘焦点和减少动态效果偏好。
- **设计图映射：** `design-gallery.html` 收录 13 张单页参考图与实际页面入口；没有单独参考图的后台页面使用已实现的默认管理风格，不使用旧截图冒充当前页面。
