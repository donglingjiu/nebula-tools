# Nova V6 设计参考

`approved-single-page/` 收录本次交付采用的 13 张独立页面设计参考图：用户前台 10 张、管理后台 3 张。

- 前台首页以水晶星环为主视觉；工作区使用明亮海天背景、玻璃质感与更高的内容可读性。
- 后台前三张参考图对应管理总览、用户管理和工具管理。其余 7 个后台页面沿用代码中已实现的后台布局，不以旧总览图冒充单页设计稿。
- `design-gallery.html` 可查看每一张参考图，并跳转到对应真实 HTML 页面。参考图用于视觉指导；页面中的按钮、表格、输入框和弹窗由 HTML/CSS/JavaScript 独立实现，并非将整张截图作为网页背景。
